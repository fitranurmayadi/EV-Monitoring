Untuk Orange Pi 5 Pro, versi terbaik adalah menggunakan Single Container (Monolith). Mengapa? Karena ThingsBoard membutuhkan RAM yang cukup besar (Java-based), dan menyatukan PostgreSQL di dalam satu container lebih efisien dalam penggunaan resource pada arsitektur ARM, namun tetap aman karena data disimpan di luar container (bind mount).

Berikut adalah panduan lengkap dan konsisten:
Langkah 1: Persiapan Folder Data

Kita akan membuat folder khusus di direktori home user Orange Pi untuk memastikan database PostgreSQL dan Log MQTT tersimpan secara permanen.
Bash

# Buat direktori utama dan sub-direktori data serta logs
mkdir -p ~/thingsboard-docker/data && mkdir -p ~/thingsboard-docker/logs

# Berikan izin akses ke user ID 799 (user default di dalam container ThingsBoard)
sudo chown -R 799:799 ~/thingsboard-docker/data
sudo chown -R 799:799 ~/thingsboard-docker/logs

# Masuk ke direktori tersebut
cd ~/thingsboard-docker

Langkah 2: Membuat File Docker Compose

Buat file konfigurasi menggunakan editor nano.
Bash

nano docker-compose.yml

Salin dan tempel kode berikut. Konfigurasi ini sudah dioptimalkan untuk PostgreSQL terbaru (internal) dan Logging MQTT:
YAML

version: '3.8'
services:
  mytb:
    restart: always
    image: "thingsboard/tb-postgres:latest"
    container_name: thingsboard
    ports:
      - "8080:9090"       # Dashboard Web
      - "1883:1883"       # MQTT Port (Penerimaan Data Sensor)
      - "7070:7070"       # Edge Service
      - "5683-5688:5683-5688/udp" # CoAP Port
    environment:
      TB_QUEUE_TYPE: in-memory
      # Memastikan logs mencatat aktivitas MQTT secara detail
      TB_LOG_LEVEL: info 
    volumes:
      - ./data:/data
      - ./logs:/var/log/thingsboard

Tekan CTRL+O, Enter, lalu CTRL+X untuk menyimpan.
Langkah 3: Menjalankan ThingsBoard

Karena ini instalasi pertama, ThingsBoard akan melakukan inisialisasi database PostgreSQL di dalam folder ./data Anda.
Bash

docker compose up -d

Penting: Proses inisialisasi pada Orange Pi 5 Pro memakan waktu sekitar 2-4 menit. Jangan terburu-buru membuka browser. Anda bisa memantau prosesnya dengan perintah:
Bash

docker compose logs -f mytb

Tunggu sampai muncul tulisan: Started ThingsBoard Server.
Langkah 4: Verifikasi & Akses

Setelah sistem berjalan, buka browser di perangkat lain yang berada dalam jaringan yang sama:

    URL: http://[IP-ORANGE-PI]:8080

    Login Tenant (Untuk buat Device/Dashboard):

        User: tenant@thingsboard.org

        Password: tenant

Langkah 5: Cara Mengetes Log Data MQTT

Untuk memastikan database mencatat data yang diterima, coba kirim data simulasi dari terminal Orange Pi Anda:

    Buka tab terminal baru.

    Instal tool MQTT (jika belum ada): sudo apt install mosquitto-clients

    Kirim data (Ganti ACCESS_TOKEN dengan token yang Anda dapat dari web dashboard):

Bash

mosquitto_pub -h localhost -t v1/devices/me/telemetry -u "ACCESS_TOKEN" -m '{"temp": 27.5, "hum": 60}'

Ringkasan Folder Konsisten

Setelah instalasi selesai, struktur folder Anda akan terlihat seperti ini:

    ~/thingsboard-docker/data: Berisi database PostgreSQL (Tabel sensor, log, user).

    ~/thingsboard-docker/logs: Berisi file thingsboard.log (Catatan aktivitas sistem).

    ~/thingsboard-docker/docker-compose.yml: File konfigurasi utama.

Tips Pro: Jika Anda menggunakan Orange Pi 5 Pro dengan NVMe SSD, letakkan folder thingsboard-docker ini di dalam mount point SSD Anda untuk performa database 10x lebih cepat dibanding MicroSD.
